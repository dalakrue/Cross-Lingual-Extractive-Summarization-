# data/ — Labeled dataset

## Files

| File | What it is |
|---|---|
| `sentence_labels.csv` | 50 articles, 1500 sentences (25 sports + 25 technology). One row per sentence. |

## Columns in `sentence_labels.csv`

| Column | Meaning |
|---|---|
| `article_id` | e.g. `sports_0001`, `technology_0001` |
| `domain` | `sports` or `technology` |
| `sentence_id` | Position in the article (0 = first sentence) |
| `sentence` | The sentence text |
| `label` | 1 = belongs in the summary, 0 = not important |
| `reference_similarity` | Similarity to the reference summary (labeling aid) |
| `weak_supervision` | Whether the label came from weak supervision |

## How it was made (Member 1 — Thet Oo Maung)

1. Collected sports + technology articles.
2. Cleaned text: removed HTML, unnecessary symbols, duplicates; normalized text.
3. Split each article into sentences.
4. Labeled each sentence 1/0 by matching it against the human-written
   reference summary (see the project report for the exact rule).

## What uses it

- `src/fasttext/fasttext_features.py` reads this file and writes
  `results/sentence_vectors.csv`, `results/article_split.csv`, `results/fasttext.model`.
- `src/fasttext/improved_features.py` reads this file (+ the split) and writes
  `results/improved_sentence_vectors.csv`, `results/improved_fasttext.model`.

Do not edit this file by hand — it is the ground truth for training and evaluation.
