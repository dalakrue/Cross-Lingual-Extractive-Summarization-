# results/ — Committed result tables

These are the real outputs of the training + evaluation runs. They are
committed so anyone can see the numbers without retraining.

| File | What it is | Produced by |
|---|---|---|
| `model_comparison.csv` | Baseline (64 FastText features): LR / SVM / RF accuracy, precision, recall, F1 | `src/training/train_classifier.py` |
| `improved_model_comparison.csv` | Improved (69 features): LR / SVM / RF | `src/training/train_improved_classifier.py` |
| `summarization_selection_results.csv` | Baseline summary selection, avg per top_k (5/7/10) | `src/evaluation/evaluate_summarizer.py` |
| `improved_summarization_selection_results.csv` | Improved summary selection, per-article + per top_k | `src/evaluation/evaluate_improved.py` |

## What is NOT committed here

- Trained binaries (`*.pkl`, `*.model`) — regenerate with the pipeline.
- Generated vector files (`sentence_vectors.csv`,
  `improved_sentence_vectors.csv`) and `article_split.csv` — regenerated by
  `src/fasttext/*.py`. See `.gitignore`.

Key numbers: improved SVM — accuracy 83.7%, precision 0.44, recall 0.90,
F1 0.60. Improved summary selection avg F1: top-5 ≈ 0.57, top-7 ≈ 0.54,
top-10 ≈ 0.48.
